# Support

## Included With Moneta Lite

Moneta Lite is provided as a free public edition.

Included:

- Documentation in `README.md`, `QUICKSTART.md` and `INSTALL.md`.
- Public issue reporting if a public repository issue tracker is enabled.

Not included:

- Private installation support.
- Server configuration.
- Custom development.
- Data recovery.

## Included With Moneta Pro

Moneta Pro includes the paid source package and documentation.

Recommended support scope:

- Help with basic installation steps.
- Clarification of `.env` configuration.
- Help creating the first admin user.
- Fixes for reproducible bugs in the original package.

Not included unless purchased separately:

- Hosting management.
- Custom features.
- Branding changes.
- Advanced server or proxy configuration.
- Database migration from unrelated systems.
- Long-term maintenance.

## Guided Installation

Guided installation is a separate paid service. It can include:

- Environment review.
- Python and dependency setup.
- `.env` configuration.
- Database migration.
- Admin user creation.
- Local access test.
- Basic security recommendations.

Recommended price range: USD 149 to USD 199.
