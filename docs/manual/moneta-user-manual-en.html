2. Financial Dashboard

The dashboard summarizes assets, liabilities, capital, income, expenses, cash flow, cards, upcoming payments and alerts.

Review first
Cash flow, card debt, exceeded categories and overdue invoices.
Suggested rhythm
Weekly review and month-end close.

3. Accounts And Categories

Create main accounts and categories before recording transactions.

ItemUseExamples
AccountsWhere money is held or owed.Bank, cash, savings, card, loan.
CategoriesTransaction classification.Payroll, groceries, transport, software.

4. Transactions

Transactions record income, expenses, transfers, card payments and collections. Only cleared transactions affect balances and accounting.

TypeImpactSpecial data
IncomeIncreases a normal account.Income category.
ExpenseDecreases a normal account.Expense category.
TransferSubtracts origin and adds destination.Destination account required.
Card paymentReduces payer account and card debt.Related card required.

5. Credit Cards

Cards track limit, debt, available credit, interest, FECI, minimum payment and recommended payment. Create a credit-card account before adding the card.

When statement values are available, enter exact statement balance, minimum payment and cash payment. Moneta prioritizes those values.

6. Invoices

Invoices can be issued or received. Moneta calculates total as subtotal plus tax and marks overdue pending invoices automatically.

7. Recurring And Subscriptions

Recurring items automate repeated expenses or income. Subscriptions use the same engine but are managed separately for services, insurance and periodic charges.

  • Supported frequencies: weekly, biweekly, monthly, quarterly and yearly.
  • Run now creates due movements and avoids duplicates.
  • Transaction type must match category type.

8. Ledger

The ledger reviews debit/credit entries. Automatic entries are created for cleared transactions and invoices.

Rule 1
An entry needs at least two lines.
Rule 2
Total debit must equal total credit.

9. Reports And Exports

Reports show cash flow, budgets, expense breakdown, invoices and recurring items. CSV exports allow backup and external analysis.

10. Operations And Support

For production instances:

python manage.py migrate
python manage.py createcachetable
python manage.py check --deploy

For support, report screen, steps to reproduce, user/edition, error message and screenshot if available.
