1. Acceso inicial

Abre la URL de tu instalacion, escribe tu usuario y clave, y presiona Entrar. En una demo local creada con datos de ejemplo, el usuario por defecto es:

Usuario: demo
Clave: demo12345
Seguridad: en produccion, cambia credenciales antes de exponer Moneta en red. Si se superan los intentos fallidos, el login se bloquea temporalmente por IP.

2. Panel financiero

El panel financiero es la vista principal de operacion. Resume activos, pasivos, capital, ingresos, gastos, flujo de caja, tarjetas, proximos pagos y alertas.

Que revisar primero
Flujo de caja, deuda de tarjetas, categorias excedidas y facturas vencidas.
Frecuencia sugerida
Revisar semanalmente y al cierre de cada mes.

3. Cuentas y categorias

Antes de registrar movimientos, crea las cuentas y categorias principales.

ElementoUsoEjemplos
CuentasRepresentan donde se guarda o debe dinero.Banco, efectivo, ahorro, tarjeta, prestamo.
CategoriasClasifican el movimiento.Nomina, supermercado, transporte, software.
  1. Entra a Configuracion.
  2. Presiona Crear cuenta o Crear categoria.
  3. Completa los campos requeridos y guarda.

4. Movimientos

Los movimientos registran ingresos, gastos, transferencias, pagos de tarjeta y cobros.

TipoImpactoDato especial
IngresoAumenta una cuenta normal.Categoria de ingreso.
GastoReduce una cuenta normal.Categoria de gasto.
TransferenciaResta origen y suma destino.Cuenta destino obligatoria.
Pago de tarjetaReduce cuenta pagadora y deuda.Tarjeta relacionada obligatoria.

Solo los movimientos confirmados afectan saldos y asientos contables.

5. Tarjetas de credito

Las tarjetas permiten controlar limite, deuda, disponible, intereses, FECI, pago minimo y pago recomendado.

  1. Crea primero una cuenta de tipo Tarjeta de credito.
  2. Entra a Tarjetas y selecciona Nueva tarjeta.
  3. Completa limite, deuda, tasas, corte y fecha limite de pago.
Si tienes datos exactos del estado de cuenta, usa saldo de estado, pago minimo y pago contado. Moneta prioriza esos valores sobre los calculados.

6. Facturas

Las facturas pueden ser emitidas o recibidas. Moneta calcula el total como subtotal mas impuesto y marca vencidas las pendientes con fecha vencida.

EstadoUso
BorradorAun no afecta contabilidad automatica.
PendienteFactura activa por cobrar o pagar.
PagadaFactura completada.
VencidaPendiente con fecha vencida.
AnuladaNo debe mantener asiento automatico.

7. Recurrentes y suscripciones

Los recurrentes automatizan movimientos repetitivos. Las suscripciones usan la misma base, pero se administran separadas para servicios, seguros y cargos periodicos.

  • Frecuencias: semanal, quincenal, mensual, trimestral y anual.
  • El boton Ejecutar ahora crea movimientos vencidos sin duplicarlos.
  • El tipo de movimiento debe coincidir con la categoria seleccionada.

8. Libro contable

El libro contable permite revisar asientos Debe/Haber. Moneta crea asientos automaticos para movimientos y facturas confirmadas.

Regla 1
Un asiento necesita al menos dos lineas.
Regla 2
Total Debe debe ser igual a total Haber.

9. Reportes y exportaciones

Los reportes ayudan a revisar flujo, presupuestos, gastos por categoria, facturas y recurrentes. Las exportaciones CSV permiten respaldar o analizar datos fuera del sistema.

  • Movimientos y facturas respetan filtros visibles.
  • Las exportaciones tienen limite de filas para proteger rendimiento.
  • Los CSV se sanitizan para evitar formulas peligrosas.

10. Operacion y soporte

En produccion, una instancia debe ejecutar migraciones y preparar la tabla de cache si usa cache en base de datos.

python manage.py migrate
python manage.py createcachetable
python manage.py check --deploy

Para soporte, reporta pantalla afectada, pasos para reproducir, usuario/edicion, mensaje de error y captura si aplica.
