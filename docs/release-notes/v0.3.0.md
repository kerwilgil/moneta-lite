# Moneta v0.3.0 — Intelligence & Interoperability

> **Borrador.** No publicar hasta la auditoría posterior a Phase 8, la estrategia
> de merge y el `tag`.

**Fecha:** _pendiente_

## Highlights

- **Cola de importaciones** con deduplicación y **aprobación humana**: todo lo que
  entra de fuera pasa por revisión antes de tocar el núcleo financiero.
- **Servidor Moneta MCP** (`2026-07-28`, stdio + Streamable HTTP oficial) con
  scopes `read` y `draft` — 15 herramientas, sin `approve` ni operaciones
  destructivas.
- **Base de interoperabilidad con IA**: la IA sugiere y crea borradores; nunca
  decide. Moneta funciona sin IA, sin API key y sin internet.
- **Centro de ayuda dentro de la aplicación** (`/ayuda/`) con búsqueda, ayuda
  contextual y respeto de las ediciones.
- **PostgreSQL validado contra una instancia real** (18.6). SQLite sigue siendo
  el modo por defecto.

## Novedades

### Cola de importaciones

`ImportBatch` + `TransactionDraft`. Deduplicación exacta por `external_id` y por
huella v2 (usuario, origen, comercio, descripción, importe, moneda, fecha, signo).
Idempotencia, sanitización de `raw_metadata`, aprobación y rollback atómicos,
rechazo y marcado de duplicados. UI para editar / aprobar / rechazar.

### Moneta MCP

SDK oficial `mcp` 2.2.x (`mcp.server.lowlevel.Server`). Protocolo moderno
`2026-07-28` y compatibilidad legacy `2025-11-25`. Transportes **stdio** y
**Streamable HTTP** (`Server.streamable_http_app`, montado en `/mcp`).

- 10 herramientas `read`, 5 `draft`.
- Sin `approve`, sin creación directa de movimientos, sin borrado, sin mutación de
  saldos, sin confirmación de pagos.
- Token con hash HMAC-SHA256 + *pepper*; se muestra una sola vez.
- Aislamiento por inquilino, rate limiting, auditoría, redacción de secretos.
- Eliminado `--allow-unauthenticated`.

### Ayuda

`/ayuda/` con índice agrupado, filtro de búsqueda cliente, artículo por módulo,
"volver" y breadcrumbs. Ayuda contextual ("? Cómo funciona") en Dashboard,
Movimientos, Tarjetas, Suscripciones, Reportes, Importaciones y MCP. i18n
`es-pa` / `es` / `en`. Los artículos Pro no aparecen en la edición Lite.

### PostgreSQL

Validado contra PostgreSQL 18.6 real:

- base creada desde cero, migraciones ida y vuelta,
- constraints, índices y claves foráneas,
- concurrencia (bloqueo de fila, `select_for_update`, transacciones atómicas),
- cola de importaciones y MCP contra PostgreSQL,
- tokens y auditoría MCP.

Se corrigieron incompatibilidades reales: `FOR UPDATE` sobre el lado nullable de
un `LEFT JOIN` (ahora `select_for_update(of=("self",))`).

### Seguridad y correcciones

- Fix de un 500 en la lista de movimientos (`SimpleNamespace` sin importar).
- `SECURITY.md`, checklist de despliegue, `secret_scan` en el flujo de release.

## Limitaciones conocidas

- Sin migración automática de datos entre backends.
- El endpoint MCP Streamable HTTP se enlaza a loopback; exponerlo requiere un
  proxy inverso autenticado.
- La ayuda in-app es contenido resumido; la referencia completa está en
  `docs/user-guide/`.
