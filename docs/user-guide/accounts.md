# Cuentas

## Qué es

Una cuenta representa un lugar donde tienes o debes dinero: banco, efectivo, ahorro, inversión, tarjeta, préstamo o capital.

## Para qué sirve

Toda operación mueve dinero entre cuentas; el balance de cada cuenta se deriva de sus movimientos.

## Campos principales

- **Tipo**: define cómo cuenta para activos, pasivos y capital.
- **Saldo de apertura**: saldo con el que empiezas a registrar en Moneta.
- **Saldo actual**: apertura más el efecto de los movimientos confirmados.
- **Moneda**: código de la divisa.

## Acciones

Crear, editar y desactivar cuentas. Eliminar solo si no tiene movimientos.

## Ejemplo

Cuenta "Ahorro" tipo Ahorro, apertura 500. Tras una transferencia de 100 desde "Banco", su saldo actual es 600.

## Notas

No edites el saldo actual a mano: registra un movimiento de ajuste para que el histórico quede explicado. Los nombres son únicos por usuario sin distinguir mayúsculas.
