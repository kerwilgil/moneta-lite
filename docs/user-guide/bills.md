# Facturas

## Qué es

Registro de facturas emitidas (a clientes) y recibidas (de proveedores).

## Para qué sirve

Seguir qué te deben y qué debes, con fecha de vencimiento y estado.

## Campos principales

- **Tipo**: emitida o recibida.
- **Subtotal e impuestos**: el total se calcula a partir de ellos.
- **Fecha de emisión y de vencimiento**.
- **Estado**: borrador, pendiente, pagada, vencida o anulada.

## Acciones

Crear, editar y eliminar. Marcar como vencidas las pasadas de fecha. Exportar a CSV.

## Notas

El subtotal debe ser mayor que cero. Anular no borra el histórico.
