# Dashboard

## Qué es

La pantalla de inicio: resume tu situación del periodo seleccionado.

## Para qué sirve

Ver de un vistazo balance real, ingresos y gastos del mes y deuda registrada.

## Campos principales

- **Balance total**: activos reales, sin límites de tarjeta.
- **Ingresos del mes**: ingresos y cobros confirmados.
- **Deuda registrada**: préstamos, cuentas por pagar y deuda real de tarjetas.
- **Tendencia de flujo**: gráfico de barras del flujo mensual, con alternativa en texto para lectores de pantalla.

## Acciones

Cambiar el periodo y usar los accesos rápidos para crear una cuenta o un movimiento.

## Notas

Es de solo lectura: no modifica saldos; los números se recalculan a partir de tus movimientos.
