# Preguntas frecuentes

## ¿Diferencia entre Lite y Pro?

Lite: dashboard, cuentas, movimientos, facturas, tarjetas, suscripciones con seguros, reportes, importaciones y MCP. Pro añade recurrentes automáticos, catálogo completo de suscripciones, libro contable, ingreso neto y exportaciones avanzadas.

## ¿NAS o servidor?

Sí, con Python disponible. Publícalo tras un proxy inverso con HTTPS o accede por VPN. `runserver` es solo para desarrollo local.

## ¿Acceso desde otra computadora?

Sí, mediante HTTPS con proxy inverso o VPN. Configura el dominio en `DJANGO_ALLOWED_HOSTS` y `DJANGO_CSRF_TRUSTED_ORIGINS`.

## ¿Mis datos salen de mi equipo?

No. Moneta es self-hosted y funciona sin conexión. La IA está deshabilitada por defecto.

## ¿Necesito clave de API de IA?

No. Moneta funciona por completo sin IA y sin clave de API.
