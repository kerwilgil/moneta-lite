# Seguros privados

## Qué es

Un apartado dentro de Suscripciones para coberturas personales: vida, salud e ingreso.

## Para qué sirve

Registrar las primas como gasto recurrente y verlas separadas del resto de servicios.

## Cómo usarlo

En Suscripciones, usa las tarjetas de "Seguros privados" para añadir una cobertura e indica el importe y la frecuencia de la prima.

## Notas

Moneta solo registra el gasto; no gestiona pólizas ni siniestros.
