# Ingreso neto (Pro)

## Qué es

Calculadora para estimar el salario neto a partir del bruto y las deducciones.

## Para qué sirve

Planificar con lo que de verdad recibes, antes de comprometer gasto fijo.

## Cómo usarlo

Introduce el salario bruto y las deducciones; revisa el neto y la capacidad mensual estimada.

## Notas

Módulo de la edición Pro. Es una simulación orientativa; no sustituye el cálculo oficial de tu jurisdicción.
