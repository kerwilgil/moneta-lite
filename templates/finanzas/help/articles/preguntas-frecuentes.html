{% trans "¿Cuál es la diferencia entre Lite y Pro?" %}

{% trans "Lite incluye dashboard, cuentas, movimientos, facturas, tarjetas, suscripciones con seguros, reportes, importaciones y MCP. Pro añade pagos recurrentes automáticos, catálogo completo de suscripciones, libro contable, ingreso neto y exportaciones avanzadas." %}

{% trans "¿Puedo usar Moneta en un NAS o servidor?" %}

{% trans "Sí, con Python disponible. Publícalo detrás de un proxy inverso con HTTPS o accede por VPN privada. runserver es solo para desarrollo local." %}

{% trans "¿Puedo acceder desde otra computadora?" %}

{% trans "Sí, mediante HTTPS con un proxy inverso o una VPN. Configura tu dominio en DJANGO_ALLOWED_HOSTS y DJANGO_CSRF_TRUSTED_ORIGINS." %}

{% trans "¿Mis datos salen de mi equipo?" %}

{% trans "No. Moneta es self-hosted y funciona sin conexión. La IA está deshabilitada por defecto y no se envía nada a servicios externos salvo que tú configures un cliente MCP." %}

{% trans "¿Necesito una clave de API de IA?" %}

{% trans "No. Moneta funciona por completo sin IA y sin clave de API." %}
